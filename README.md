# 半导体，从零开始

面向零基础读者的本地教学网站。首页按基础概念、企业分工、晶圆制备与制造流程、基础讲解（七章入口）组织；十四个流程入口、七章阅读、六幅静态知识图及十二项设备机制演示（含独立刻蚀剖面）；演示在对应流程详情页内就地播放，不需要跳到另一个页面；七章基础正文只保留知识与图示，不含演示，也不设每章底部的链接条（只保留页首七章目录）；所有内页页头提供「返回首页」。晶圆传输与自动化置于贯穿制造区域，以图文交接路径说明设备协作。

流程详情把设备演示嵌在本环节内，演示下方是直接可见的前置解释与工艺目的、进入状态、设备及作用、离开状态、关联环节、常见误解六项基本讲解。详情页面不再保留重复的演示入口按钮组。知识正文统一保存在 chapters.html；推荐下一学习主题不代表实际生产工序。刻蚀入口使用 etch.html 的二维设备/材料双视图，七阶段解释粒子生成、鞘层、反应与排气，并返回刻蚀详情；原共享薄膜图形化演示保留。封装从裸片装配开始，返回原详情。两幅设备功能剖面及一组四状态局部互连示意不增加装饰动画；手机播放控制与短状态说明在播放器内保持可用。

## 运行

双击 启动App.bat，或在本目录执行 node server.mjs。访问 http://127.0.0.1:8787/；原 /learn.html 地址仍可用。使用 Node 内置 HTTP/fs 模块，无第三方依赖。PORT/HOST可指定端口/监听地址，默认只监听127.0.0.1:8787。

需先安装Node.js。浏览器自动化回归使用Windows上的Microsoft Edge固定安装路径；网站运行本身不依赖这些测试工具。Git规则保留两份bat脚本的Windows CRLF换行及UTF-8无BOM格式。

## 内容与边界

讲解直接展开，不需要注册；动画为设备功能与材料变化的教学重建，不是实机录像、操作规程或量产配方。可播放、暂停、分步和重播，减少动态/WebGL不可用时保留文字；完整章节无需JavaScript也可阅读。企业与设备相关知识保留；界面不再展示资料来源、延伸阅读与跨章跳转，阅读栏在页面内居中，页面采用深色科技底与浅色阅读面板。新增技术事实仍按第一手资料核对，但不在界面列出出处。
