# 半导体，从零开始

面向零基础读者的本地教学网站。首页按基础概念、企业分工、晶圆制备与制造流程组织；十四个流程入口、七章阅读、六幅静态知识图及十一项设备机制演示。晶圆传输与自动化置于贯穿制造区域，以图文交接路径说明设备协作。

流程详情包含直接可见的前置解释，以及工艺目的、进入状态、设备及作用、离开状态、关联环节、常见误解六项基本讲解。知识正文统一保存在 chapters.html；推荐下一学习主题不代表实际生产工序。共享演示保留来源入口，刻蚀从相应步骤开始，封装从裸片装配开始，返回原详情。新增两幅设备功能剖面及一组四状态局部互连示意，不增加装饰动画；手机播放控制与短状态说明在播放器内保持可用。

## 运行

双击 启动App.bat，或在本目录执行 node server.mjs。访问 http://127.0.0.1:8787/；原 /learn.html 地址仍可用。使用Node内置HTTP/fs模块，无数据库和第三方依赖。PORT/HOST可指定端口/监听地址，默认只监听127.0.0.1:8787。

需先安装Node.js。浏览器自动化回归使用Windows上的Microsoft Edge固定安装路径；网站运行本身不依赖这些测试工具。Git规则保留两份bat脚本的Windows CRLF换行及UTF-8无BOM格式。

## 内容与边界

讲解直接展开，不需要注册；动画为设备功能与材料变化的教学重建，不是实机录像、操作规程或量产配方。可播放、暂停、分步和重播，减少动态/WebGL不可用时保留文字；完整章节无需JavaScript也可阅读。企业与设备相关知识及其官方功能来源保留，旧厂商数据库/搜索/对比/维护查询台已移除。

## 验证

node tests/retired-query-console.mjs 验证旧页面/接口/数据退役、根入口与HTTP边界。
node tests/beginner-learning.mjs 验证教学导航、十四流程详情、实际三维帧与状态、控件、键盘、1440/390/320/768排版和回退。
node tests/product-review-fixes.mjs 验证六项讲解、前置知识、十三条演示往返、来源参数边界及手机画面/控件/短说明共同可见。
node tests/product-review-round2.mjs 验证详情演示去重、标题关联、材料制备范围、来源重播及320×568/360×640/390×844/844×390画面与完整状态共同可见。
node tests/windows-launchers.mjs 隔离验证启动、停止脚本的格式及CMD中文解析，不执行真实服务操作。
node .planning/review-fixes-20261002/verify.mjs 在临时回环端口执行第一轮三组检查（退役边界、第一轮专项、教学全量）；结束后关闭自建服务与浏览器，不启动或停止正式8787服务。
node .planning/review-round2-20261002/verify.mjs 在临时回环端口串行执行四组检查；--targeted只运行第二轮专项。第二轮审核及整改记录见docs/product-review-round2-20261002.md。

## 恢复

旧查询台仅保存在不对外提供访问的离线归档 ../retired-query-console-20261002/。before/含替换前服务/页面/测试和一致SQLite快照；removed/含从活动项目移出的原文件。完整恢复需先停止教学服务并按归档恢复旧服务、页面、模块和data；不要只恢复数据库。当前静态服务不会自动生成任何旧数据。

GitHub仓库包含当前教学版本的完整源码、测试、验证脚本、说明文档及规划记录；本机历史备份、退役归档、运行日志、测试结果和截图不上传。克隆后无需旧数据库即可运行。报告中的本地备份及截图路径仅指原开发环境；运行验证可重新生成当前结果。
