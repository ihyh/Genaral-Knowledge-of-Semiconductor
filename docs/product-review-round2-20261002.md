# 第二轮产品审核与整改

日期：2026-10-02。对象：当前8787教学网站，不是已退役的工艺查询台。重新从零基础读者的流程入口、正文范围、设备演示上下文和常见手机视口检查；没有把上一轮测试通过视为教学效果达标。

## 审核结论及已实施整改

三模块首页方向正确，应保留“概念 → 企业分工 → 制备与制造全景”。本轮主要不足是演示上下文丢失、部分短屏看不全画布，以及基础与扩展内容界限不清。以下问题均有修改前浏览器证据，不是仅凭偏好重排。

| 优先级与问题 | 为什么影响初学者 | 本轮修改与验收 |
| --- | --- | --- |
| P1 重播与末步重新播放丢失来源 | 刻蚀和封装原本从第2步进入，却回到增加薄膜或晶圆测试，容易混淆当前工艺 | 使用已校验的来源起始步重播；独立入口仍从0开始。5组场景覆盖普通重播、末步重启及减少动态 |
| P1 短手机屏与横屏控件遮挡画布 | 原320×568工具栏约353.5px；844×390画布底约525px。无横向溢出不代表可以同时操作并观察 | 短竖屏精简控制排布，横屏控制栏与画布并排；来源声明移到播放器前。完整材料状态不截断、不隐藏。新增实际边界与画布命中检查 |
| P2 9个核心详情重复演示入口 | 同一个演示在正文与底部重复，增加视觉噪声和选择成本 | 聚焦详情只保留底部统一演示入口；全文阅读仍保留原入口。feedback的两个不同主题分别保留一次 |
| P2 材料详情复用整章、基础与扩展混排 | 本应先理解晶圆如何制备，却同时看到整个材料比较及重复输入输出 | 新设wafer-preparation规范小节；保留六项讲解、晶体生长与表面加工说明和来源，删除重复卡片。SiC/GaN及其他制造材料在全文保留并有扩展链接；封装方案对照标注扩展阅读 |

| P2 标签及术语可读性不足 | 局部材料标签11px偏小；用未解释的“载流子”说明掺杂，解释门槛没有降低 | 标签改12px并检查三种宽度下实际文字边界；前置说明改为电流、电荷和受控引入成分的直接解释 |
| P2 成膜结束状态混入后续图形转移 | 共享演示若不区分范围，读者可能把刻蚀后的开口当作成膜结果 | 成膜来源明确“形成薄膜、尚无加工开口”，标明后续图形化不是成膜本身；共享演示与几何保持不变 |

## 保留与变更边界

首页未增加新模块；14流程入口、7章、原6幅知识图、11项设备演示保留。全部内容直接显示，不新增折叠、测验、账户、装饰动画或依赖。晶圆传输与自动化仍作为贯穿制造的图文路径。正文仍以chapters.html为唯一来源，step.js只聚焦提取；材料扩展内容没有删除。

本次仅修改7个public文件及相关测试、文档、规划。learn.html、step.html、server.mjs、启动/停止脚本与退役归档未改动。既有规范性技术限定与资料链接保留；不把教学几何当作实机结构，不提供生产参数，不改变原动画加工几何。
